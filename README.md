# أمل الطفولة — إدارة الجمعية

موقع عربي من اليمين إلى اليسار لإدارة مالية الجمعية والمنتسبين والمستفيدين والمساعدات والتقارير، بتصميم مستوحى من شعار أمل الطفولة.

## الوظائف
- إضافة وتعديل وحذف السجلات وأرقام تعريفية تلقائية، بما فيها ملفات العمال.
- بطاقات العمال والمستفيدين مع بياناتهم وأرقامهم، فرديًا أو دفعة واحدة حسب نتائج البحث.
- تقارير PDF لكل قسم وملف وبطاقات؛ تفتح نافذة الطباعة، ثم اختر «حفظ بصيغة PDF». بطاقات المستفيدين تشمل بيانات الأسرة والتصنيفات وسجل المساعدات.
- تصنيف المستفيد ضمن أكثر من فئة هشاشة.
- سجل مساعدات مرتبط بملف المستفيد. المساعدات النقدية تحتسب ضمن المصروفات تلقائيًا.
- تقارير شهرية وسنوية وتصدير CSV وطباعة إلى PDF.
- قاعدة بيانات SQLite للتشغيل المحلي، وواجهة متوافقة مع D1 للاستضافة.
- سجل تدقيق لتعديلات البيانات.

## الحالة الحالية
الواجهة جاهزة واختبارات واجهة البيانات ناجحة. لم يُنشر الموقع بعد. إنشاء ترحيلات قاعدة البيانات وتجهيز الاستضافة ما زالا مطلوبين. لا تستخدمه لبيانات حقيقية قبل تأمين الاستضافة والتحقق النهائي.

## التشغيل بعد تنزيل الأدوات
يتطلب Node.js 24 أو أحدث.
```sh
npm install
npm run db:generate
npm test
npm run dev
```
ثم افتح http://localhost:3000. البيانات المحلية في `data/emel.sqlite`، وهي غير مضمنة في المستودع.

## البناء
```sh
npm run build
```
ينتج Worker في `dist/server/index.js`. يحتاج نشره إلى ربط D1 باسم `DB` وتطبيق ترحيلات `drizzle/`. الوصول إلى لوحة الإدارة يجب أن يكون خاصًا؛ الكود يعتمد في الاستضافة على سياسة وصول المنصة. التشغيل المحلي مخصص للتطوير فقط.

## ملاحظات مالية
- لا تسجل المساعدة النقدية مرة أخرى كمصروف؛ تُحتسب من سجل المساعدات.
- حالة اشتراك المنتسب لا تنشئ إيرادًا تلقائيًا؛ سجل المبلغ المستلم في الإيرادات.
- تغيير العملة يغير وحدة العرض فقط.
